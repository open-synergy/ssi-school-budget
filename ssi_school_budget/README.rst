=============
School Budget
=============

Replicates the Budget Sekolah RAB simulator inside Odoo: schools plan their
expense budget per category, and the module reverse-computes the Uang
Pangkal (UP) and Uang Sekolah (US) tariffs from that cost base.

This module ships with no seed data. Income, expense, and investment
categories must be configured by the user/client before use.


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school-budget
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *School Budget*
6.  Install the module
